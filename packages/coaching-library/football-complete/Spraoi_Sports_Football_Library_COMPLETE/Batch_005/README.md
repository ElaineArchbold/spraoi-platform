# Spraoi Sports Football Library — Batch 005

This batch contains 18 football activity records from the complete GAA planner scrape.

Files:
- `activities_batch_005.json`
- `skills_batch_005.json`
- `challenges_batch_005.json`
- `source_register_batch_005.json`

The structure matches the earlier Spraoi Sports Kiro library format.

Source-backed fields include activity title, description, organisation, variations, equipment and source URL.
Where the source did not specify duration, player range, area size or exact age band, conservative placeholder values were added for schema compatibility and must be reviewed before production use.
